| 質問 | 採用した質疑の内訳 | 質疑数 |

医療機器の承認審査は、ワクチン・医薬品の別論点を除外できていますが、関連する質問と答弁の取得が十分ではありません。再検索後も採用0件であり、関連会議録が存在しないことを意味しません。
