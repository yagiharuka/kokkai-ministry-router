# 国会答弁・所管省庁ナビ

質問案を入力すると、国立国会図書館の国会会議録検索APIから関連会議録を取得し、議員の質問に続く政府側答弁者の肩書きを省庁に対応づけます。類似質問の答弁担当を重みづけして割合で表示します。

## ローカル起動

Python 3で `python server.py` を実行し、http://127.0.0.1:8765 を開いてください。追加パッケージは不要です。外部通信ができる環境が必要です。質問全文は外部送信せず、抽出した検索語だけを国会図書館に送ります。

## 解釈上の注意

表示する割合は取得した類似事例の分布であり、校正済みの将来予測確率ではありません。直後の複数答弁を複数省庁に配分します。答弁者の役職が「国務大臣」のみの場合や、質問が複数発言にまたがる場合など、抽出できないことがあります。正式な所管の確認には担当部局の判断が必要です。
