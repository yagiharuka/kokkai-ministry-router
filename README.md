# 国会答弁・所管省庁ナビ

質問案を入力すると、国立国会図書館の国会会議録検索APIから関連会議録を取得し、議員の質問に続く政府側答弁者の肩書きを省庁に対応づけます。類似質問の答弁担当を重みづけして割合で表示します。

## できること

- 質問案から関連する国会会議録を検索する
- 議員質問の直後に答えた政府側答弁者の肩書きを省庁ラベルに変換する
- 類似質疑の分布から「経済産業省 40% / 厚生労働省 35%」のような候補割合を返す
- 会議録から `質問 → 答弁者 → 省庁ラベル` の教師データをJSONL/CSVで作る
- 作成した教師データで簡易分類器を評価する

## ローカル起動

Python 3で `python server.py` を実行し、http://127.0.0.1:8765 を開いてください。追加パッケージは不要です。外部通信ができる環境が必要です。質問全文は外部送信せず、抽出した検索語だけを国会図書館に送ります。

## 教師データを作る

まずは省庁ごとに出やすい政策語で会議録を集めます。国立国会図書館APIへの負荷を避けるため、検索は直列で数秒間隔を空けます。

```sh
bash scripts/collect_dataset.sh
```

直接指定する場合は次の形です。

```sh
python -m router.ministry_router collect \
  --keyword "半導体" \
  --keyword "医療機器" \
  --keyword "労働" \
  --limit 20 \
  --out data/labeled_pairs.jsonl
```

CSVにしたい場合:

```sh
python -m router.ministry_router csv \
  --data data/labeled_pairs.jsonl \
  --out data/labeled_pairs.csv
```

## 割合を予測する

作った教師データを使って、質問案に近い省庁を割合で返します。

```sh
python -m router.ministry_router predict \
  --data data/labeled_pairs.jsonl \
  "医療機器の国内開発を促進するため、研究開発支援と薬事承認の迅速化をどう進めるのか。"
```

## 精度を見る

簡易的にデータを訓練用・検証用に分け、トップ1が正解省庁と一致した割合を出します。

```sh
bash scripts/evaluate_dataset.sh
```

## 解釈上の注意

表示する割合は取得した類似事例の分布であり、校正済みの将来予測確率ではありません。直後の複数答弁を複数省庁に配分します。答弁者の役職が「国務大臣」のみの場合や、質問が複数発言にまたがる場合など、抽出できないことがあります。正式な所管の確認には担当部局の判断が必要です。

## 次の改善候補

- 検索語を手作業ではなく、省庁別の政策語リストから広く展開する
- 「国務大臣」のみの肩書きを、発言者名と当時の閣僚名簿で補完する
- 複数省庁が続けて答弁した場合をマルチラベルとして評価する
- 年度・委員会・会議種別で訓練データと評価データを分け、過学習を見つける
- TF-IDF/BM25や埋め込みモデルを導入し、現在の素朴な重みづけと比較する
